# T-13 — Loan persistence and concurrent inventory

Run `./scripts/test-integration.ps1`.
Verified on 2026-10-14 with PHP 8.5.11 and PostgreSQL 16.15:
**68 tests, 285 assertions, exit 0**.

Four concurrency tests run separate PHP processes and database connections.
A barrier forces both last-copy operations to read the same inventory version:
exactly one commits and the other receives BOOK_NOT_AVAILABLE. Additional tests
prove the member-wide limit for simultaneous different books, one inventory
increment for simultaneous duplicate returns, and two increments for distinct
items of one book whose versions were read simultaneously.

Database tests also verify complete rollback on a multi-item failure, stored
snapshots, derived loan filters, overdue queries and frozen aggregate reports.
No version column or extra table was added; xmin remains adapter-local.

The required actual HTTP 201/409 pair subsequently passed through the authenticated
adapter in [T-16](T-16.md). Together, the forced version-race tests and real HTTP
execution complete the combined T-13/RNF-2 evidence.
