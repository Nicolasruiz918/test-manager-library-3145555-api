# T-21 — Isolated demonstration business time

BusinessClock accepts an optional explicit UTC environment instant only in
demo/testing mode. The standard path always reads real UTC time. Production
rejects an override before library:install can provision the database. This
implements the existing Clock port without changing any API or physical column.

BusinessClockTest verifies historical business time, real JWT issuance and
verification, real-time restoration and rejection of a production override.
The tool's demo.ps1 recreates the API for the two phases and restores real time
in its finally path. All demo writes still go through the existing API.

Full regression on 2026-10-14 using `pwsh -File scripts/test-integration.ps1`:
**90 tests, 988 assertions, exit 0** on PHP 8.5.11 / PostgreSQL 16.15. This includes
domain, application fakes, adapters, architecture, schema, startup, real HTTP,
all fourteen business error codes and independent-process concurrency tests.
The disposable test database was removed; application data was retained.

The sibling tool's evidence/T-21.md records actual 40/10/15/3 demonstration counts
and the separate 5,000-book HTTPS benchmark. This local disk deployment does not
claim a configured or tested production S3 deployment.
