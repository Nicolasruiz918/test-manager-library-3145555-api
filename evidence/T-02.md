# T-02 — Initial PostgreSQL schema

Verified on 2026-10-14 with PHP 8.5.11 and PostgreSQL 16.15.

Run `docker compose build`, then `./scripts/test-integration.ps1` from PowerShell.
The script creates an isolated PostgreSQL database in tmpfs, runs the tests and
removes only that test stack. It exits with the test process status.

Observed: **7 tests, 65 assertions, exit 0** (four schema tests and three health
tests). The database began without application tables. The Laravel migration
created exactly the six specified tables and 30 columns, with no column default,
five foreign keys, six primary keys, 15 indexes, the initial inventory range
check and the five exact category rows. Repeating the migration changed nothing.
A rollback removed both schema changes and migration bookkeeping.

The supported migration entry point is `php artisan library:migrate`. Its
transactional schema-comment history avoids adding Laravel's seventh migration
table. The decision is recorded in the docs repository's plan. T-18 checks are
deliberately still pending; the initial schema is not claimed to include them.
