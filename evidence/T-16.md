# T-16 — HTTP contract and real transport

Run `./scripts/test-integration.ps1` after `docker compose build`.
Verified on 2026-10-14 with PHP 8.5.11 and PostgreSQL 16.15:
**80 tests, 958 assertions, exit 0**.

The contract suite exercises every specified route, every one of the fourteen
business error codes, the common error shape, creation/detail/search/update/
deletion, user and member workflows, loan filters, return/overdue/report behavior,
all protected routes without tokens and every admin route with a librarian token.
It verifies Spanish errors, role checks before lookup, nullable covers, pagination,
frozen history, CORS origin restrictions and sanitized unexpected-error logging.

LiveHttpTest starts a four-worker PHP HTTP server with the real Laravel kernel
and PostgreSQL. Independent authenticated clients requesting the last copy produce
**201 and 409 BOOK_NOT_AVAILABLE**, with one stored loan and zero availability.
This completes the HTTP portion of T-13/RNF-2 alongside its forced version-race tests.

The same live server accepts an actual multipart **PUT** containing a 2 MiB PNG
with 200 and rejects a 3 MiB image with 422 VALIDATION_ERROR. This completes T-15's
transport evidence without changing the endpoint method. Server logs contain
neither the signing secret nor the Bearer token. TLS is separate T-20 evidence.
